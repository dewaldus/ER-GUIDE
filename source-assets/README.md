# Source assets archive

This folder contains retained source and legacy material that is not loaded by the production website and must not be uploaded to the public web bucket.

- `legacy-media/` contains earlier media, screenshots and design-source files.
- `legacy-globe/` contains superseded globe assets and code.
- `unverified-logos/` contains logo files that are not used by the approved client strip. Confirm the organisation and artwork before moving any logo into `site/assets/client-logos/`.

The production deployment source is the separate `site/` folder.
